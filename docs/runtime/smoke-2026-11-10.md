## Setup and artifacts

- `motion2d_easy` (`kinder/Motion2D-p0-v0`), no primitives, strict blackbox,
  Apptainer, `codex_gpt56sol` (`gpt-5.6-sol`, medium), Codex CLI 0.153.4.
- Replicate seed 42; evaluation master seed 314159; 10 episodes, 1000-step cap,
  60-second policy-time limit; two determinism checks; video rendering disabled.
- Frozen detached worktrees and matching images, run sequentially. Both used the
  existing host interpreter and KinDER installation; this was not a dependency
  upgrade. Package versions, source paths and image hashes are in `manifest.json`.
- Local artifacts: `outputs/runtime-parity-2026-11-10/`. Each arm retains results,
  resolved Hydra config, invocation, agent trace and the sandbox's policy Git
  history. `run_pair.py`, `replay.py` and `compare.py` preserve the commands and
  comparison. Outputs are local and ignored; temporary worktrees/images removed.
- Final policy commits: before `0c6ce7cba372fb9318c7553fcb2bc84c6806f8f7`;
  after `091f5f72afac3ee394e0fa391dcfe714da52eeb5`.

For each source revision, with its matching strict image, the synthesis command
was the shared interpreter running `experiments/run_experiment.py` with:

```text
environment=motion2d_easy approach=agentic approach/backend=codex_gpt56sol
primitive_level=none approach.container_backend=apptainer
approach.blackbox=true approach.blackbox_strict=true approach.max_budget_usd=2.0
replicate_seed=42 eval_seed=314159 num_eval_tasks=10 max_steps=1000
eval_timeout=60 determinism_check_num_episodes=2 render_videos=false
hydra.run.dir=<absolute-output-directory>
```

Set `PYTHONPATH=<checkout>/src:<checkout>` and run from that checkout. For saved
policy replay add `approach.load_dir=<absolute-before-output-directory>` and use
a fresh output directory. This bypasses model calls. Both replay results matched
exactly on per-episode reward/steps/success and determinism checks; timings were
excluded from equality comparisons.

## What this exercised

Both agents created and committed policies, queried the environment through the
isolated transport, ran development tests and finished with loadable policies.
The after agent debugged a goal-boundary mistake and successfully called
`render_state` once, exercising the new image-bytes transport and client-local
PNG output. Before did not call a render tool. Neither run tested `render_policy`.
Environment services shut down without remaining task processes.

This is one easy task and one synthesis per version, not broad behavioral parity
or a model-performance comparison. Claude and cluster execution remain untested.
Environment and final evaluation still execute on the host in this layer; these
runs do not validate the planned isolated evaluation or environment editing.
